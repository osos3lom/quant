# تمارين الحوسبة الكمية

منصة تعليمية عربية تفاعلية لتعلّم الحوسبة الكمية، بجناحين متكاملين:

- **التمارين** (`/exercises`): 6 وحدات و60 سؤالاً مع تغذية راجعة فورية وحلول رياضية خطوة بخطوة بترميز ديراك.
- **الدروس التفاعلية** (`/lessons`): 21 دفتراً بأسلوب Jupyter عبر ثلاثة مستويات إتقان، **يُشغّل بايثون داخل المتصفح** عبر Pyodide و WebAssembly.

التطبيق **ثابت بالكامل** (`output: 'export'`): لا خوادم ولا قواعد بيانات ولا تنفيذ من جهة الخادم، ويُحفظ تقدّم المستخدم في `localStorage` على جهازه.

| المجال | التقنية |

## النشر على Firebase Hosting (خطة Spark المجانية)

المشروع مهيأ مسبقاً: `next.config.ts` يستعمل `output: 'export'` و `images.unoptimized`، و`firebase.json` يشير إلى مجلد `out`.

```bash
npm install -g firebase-tools
```

```bash
firebase login
```

بعدها عدّل اسم المشروع في `.firebaserc` ليطابق مشروعك في Firebase، ثم:

```bash
npm run deploy
```

يقوم الأمر ببناء التصدير الثابت ثم رفعه (`firebase deploy --only hosting`)، ويصبح الموقع متاحاً على `https://<project-id>.web.app`.

## منصة الدروس التفاعلية

ثلاثة مستويات إتقان مستوحاة من منهج QWorld:

| المسار | الرمز | المحتوى | الدفاتر |
| --- | --- | --- | --- |
| المستوى البرونزي | QPrep | مرحلتان: بايثون والجبر الخطي ثم الأدوات العددية | 15 |
| المستوى الفضي | QSilver | حالات الكيوبت والتراكب، البوابات الأحادية وكرة بلوخ، التشابك وحالات بيل | 3 |
| المستوى الذهبي | QGold | خوارزمية غروفر، ارتداد الطور وتقدير الطور، تصحيح الأخطاء عملياً | 3 |

### مرحلتا المستوى البرونزي

**المرحلة الأولى — بايثون والجبر الخطي (12 دفتراً، بايثون صِرف بلا مكتبات عددية):**
تتبع أقسام المادة الأصلية قسماً بقسم: مقدمة إلى دفاتر Jupyter · مرجع سريع لـ Python · الرسم باستخدام Matplotlib · أساسيات المتغيّرات · أساسيات الحلقات · أساسيات الجمل الشرطية · أساسيات القوائم · المتجهات · الضرب القياسي · المصفوفات · الضرب التنسوري · التمارين النهائية.

**المرحلة الثانية — الأدوات العددية (3 دفاتر):**
مدخل إلى numpy · الجبر الخطي بـ numpy · حالات الكيوبت بـ numpy. تُعاد فيها العمليات نفسها بأدوات numpy مع مقارنة النتائج بالتنفيذ اليدوي، وهي الجسر إلى المستوى الفضي.

مصدر مادة المستوى البرونزي مذكور في قسم [المصدر العلمي](#المصدر-العلمي-والمؤلفون) أدناه.

### كيف يعمل تشغيل بايثون بلا خادم

1. عند أول ضغطة على **تشغيل** يُنشئ `lib/usePyodide.ts` عامل ويب من `public/qpy-worker.js`.
2. العامل يحمّل Pyodide من CDN ثم يحقن طبقة بايثون صغيرة تدير نطاقات الدفاتر.
3. كل دفتر له **نطاق متغيّرات مستقل يستمر عبر الخلايا**، تماماً كنواة Jupyter.
4. تُحمَّل الحزم تلقائياً من جُمَل `import` عبر `loadPackagesFromImports`، فـ `numpy` و `matplotlib` جاهزتان عند الحاجة.
5. المخرجات تُلتقط في بايثون (`stdout` و `stderr` وقيمة آخر تعبير)، وأشكال matplotlib تُحوَّل إلى PNG بصيغة base64 وتُعرض تحت الخلية.
6. تشغيل الشيفرة داخل عامل مستقل يعني أن حلقة لانهائية **لا تُجمّد الواجهة**؛ يكفي زر **إيقاف** لإنهاء العامل وإعادة تشغيل النواة.

### أنواع الخلايا

- **نصية**: شرح عربي بصيغة Markdown مع KaTeX، وصناديق ملاحظات (`note` / `tip` / `warning`).
- **شيفرة**: قابلة للتعديل والتشغيل، مع شارة حالة `[ ]` و `[*]` و `[1]` و `[!]`.
- **تمرين تفاعلي**: قالب بدء، وزر **تحقّق من الحل** يشغّل شيفرة تحقّق بايثونية في النطاق نفسه، وتلميحات متدرّجة وحل نموذجي.

التحقق من الحلول يعتمد على `assert` برسائل عربية، فتظهر رسالة المُقيِّم نفسها للمتدرّب عند الفشل — مثال من دفتر المتجهات:

```python
assert abs(r[0] - 0.6) < 1e-9, "المركّبة الأولى للمتجه [3,4] بعد التطبيع هي 0.6."
```

### تجربة الهاتف

محرّر الشيفرة يعرض شريط رموز سريعة (إزاحة، `:`، `()`، `[]`، `{}`، `""`، `==` …) فوق لوحة المفاتيح الافتراضية، مع إزاحة تلقائية بعد النقطتين، ودعم `Tab` و `Shift+Tab` و `Ctrl+Enter` للتشغيل.

## ملاحظات تقنية

- **الرياضيات داخل RTL:** كل معادلة تُغلَّف في عنصر `dir="ltr"`، والمعادلات العريضة تُمرَّر أفقياً داخل حاويتها بدل كسر تخطيط الصفحة. مكوّن `MathText` يقسم النص العربي على `$...$` ويُبقي علامة الترقيم ملتصقة بالمعادلة عند الالتفاف.
- **KaTeX لا يملك مقاييس محارف عربية**، لذا تبقى كل صيغ `math` خالية من العربية، ويُكتب الشرح العربي في حقول النص المجاورة (`text` / `explanation`).
- **الوضع الليلي** يُطبَّق عبر سكربت صغير في `<head>` قبل أول رسم لتفادي وميض الشاشة.
- **التخزين المحلي** يُقرأ عبر `useSyncExternalStore` مع لقطة خادم فارغة، فلا يحدث اختلاف تصيير (hydration mismatch).
