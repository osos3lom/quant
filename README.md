# ⚛️ تمارين الحوسبة الكمية (Quantum Exercises)

منصة تعليمية تفاعلية باللغة العربية لإتقان الحوسبة الكمية والفيزياء الرياضية، تعتمد على **السرد البصري والتفاعل المباشر** بدل الشرح النظرية الجاف.

🔗 **الموقع المباشر**: [https://kammiyah.web.app](https://kammiyah.web.app)

---

## 🌟 مميزات المنصة

### 1. السرد البصري السينمائي (`Landing Page`)
- **سحابة الكيوبت الثلاثية الأبعاد** (`Hero Particle Qubit Core`): محاكاة تفاعلية بسحابة احتمالات كمية وحقل مغناطيسي.
- **مقارنة التراكب والبت الكلاسيكي** (`Paradigm Shift`): مقارنة تفاعلية بين النبضة الكلاسيكية الثنائية وتداخل موجات التراكب الكمي.
- **كرة بلوخ التفاعلية** (`3D Bloch Sphere Manipulator`): التحكم بمتجه الحالة وزوايا الطور في فضاء هيلبرت مع حساب فوري للاحتمالات.
- **حقل التشابك الكمي** (`Bell State Entanglement`): محاكاة حرة لحالة بيل تثبت انهيار حالة الكيوبتين المتشابكين فورياً عبر المسافة.
- **مستكشف الأركان الستة** (`Spatial Pillars Navigator`): استكشاف تفاعلي لأركان الحوسبة الكمية مع معاينة حية لكل مسار.

### 2. التمارين والإثباتات الرياضية (`/exercises`)
- 6 مسارات تعليمية شاملة (الكيوبتات، البوابات، التشابك، القياس، الخوارزميات، وتصحيح الأخطاء).
- إثباتات رياضية خطوة بخطوة بترميز ديراك وتغذية راجعة فورية.

### 3. دروس بايثون التفاعلية (`/lessons`)
- بيئة دفاتر Jupyter تشغّل كود بايثون حقيقي بالكامل داخل المتصفح بواسطة WebAssembly و Pyodide وبدون خوادم خارجية.

### 4. واجهة زجاجية عائمة واستجابة شاملة (`Floating Glass UI`)
- شريط تنقل علوي عائم بحواف دائرية على الحواسيب وشريط تنقل سفلي تفاعلي على الجوال.
- دعم متكامل للوضعين الداكن والنهاري بالتوافق مع خط Tajawal واتجاه الخط العربي.

### 5. تنفيذ محلي 100% وخصوصية كاملة (`Client Privacy`)
- بناء ثابت بالكامل بدون خوادم أو قواعد بيانات، وتُحفظ نقاط الخبرة وتقدم المحاولات محلياً في المتصفح.

```bash

```
