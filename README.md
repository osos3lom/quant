# تمارين الحوسبة الكمية

منصة تعليمية عربية تفاعلية لتعلّم الحوسبة الكمية بالتمرين: **6 وحدات** و**60 سؤالاً** مع تغذية راجعة فورية وحلول رياضية خطوة بخطوة بترميز ديراك.

التطبيق **ثابت بالكامل** (`output: 'export'`): لا خوادم ولا قواعد بيانات، ويُحفظ تقدّم المستخدم في `localStorage` على جهازه.

---

## التقنيات

| المجال | التقنية |
| --- | --- |
| الإطار | Next.js 15 (App Router) + TypeScript |
| التنسيق | Tailwind CSS v4 مع دعم RTL عبر الخصائص المنطقية (`ms-`, `pe-`, `start-`) |
| الرياضيات | KaTeX — تُعرض بالاتجاه LTR داخل صفحة RTL |
| الخط | Tajawal عبر `next/font/google` (مُستضاف ذاتياً وقت البناء) |
| الأيقونات | lucide-react |
| التخزين | `localStorage` (نقاط الخبرة، الدقة، سلسلة الأيام، تقدّم الوحدات) |

## النشر على Firebase Hosting (خطة Spark المجانية)

المشروع مهيأ مسبقاً: `next.config.ts` يستعمل `output: 'export'` و `images.unoptimized`، و`firebase.json` يشير إلى مجلد `out`.

```bash
npm install -g firebase-tools
```

```bash
firebase login
```

بعدها عدّل اسم المشروع في `.firebaserc` ليطابق مشروعك في Firebase، ثم:

```bash
npm run deploy
```

يقوم الأمر ببناء التصدير الثابت ثم رفعه (`firebase deploy --only hosting`)، ويصبح الموقع متاحاً على `https://<project-id>.web.app`.

## المحتوى العلمي

| # | الوحدة | التصنيف | الصعوبة |
| --- | --- | --- | --- |
| 1 | الكيوبتات والتراكب الكمي | الكيوبتات | مبتدئ |
| 2 | البوابات الكمية الأحادية والمتعددة | البوابات | متوسط |
| 3 | الدوائر الكمية والتشابك | الدوائر | متوسط |
| 4 | القياس الكمي ومصفوفة الكثافة | القياس | متقدم |
| 5 | الخوارزميات والبروتوكولات الكمية | الخوارزميات | متقدم |
| 6 | تصحيح الأخطاء الكمية وأساسيات العتاد | تصحيح الأخطاء | خبير |

نوعا الأسئلة: **اختيار من متعدد** (مع تفنيد لكل خيار خاطئ) و**تعبئة الفراغات** لمعاملات الاتساع وعناصر المصفوفات.

### كيف تُقيَّم إجابات الفراغات

يقبل المُقيِّم الصيغ المكافئة: الكسور (`1/2`)، الأعداد العشرية (`0.5`)، النسب (`50%`)، الجذور (`sqrt(3)/2` أو `√3/2`)، صيغ LaTeX (`\frac{\sqrt{3}}{2}`)، والأرقام العربية الهندية (`١/٢`)، مع هامش تسامح عددي للقيم التقريبية.

## ملاحظات تقنية

- **الرياضيات داخل RTL:** كل معادلة تُغلَّف في عنصر `dir="ltr"`، والمعادلات العريضة تُمرَّر أفقياً داخل حاويتها بدل كسر تخطيط الصفحة. مكوّن `MathText` يقسم النص العربي على `$...$` ويُبقي علامة الترقيم ملتصقة بالمعادلة عند الالتفاف.
- **KaTeX لا يملك مقاييس محارف عربية**، لذا تبقى كل صيغ `math` خالية من العربية، ويُكتب الشرح العربي في حقول النص المجاورة (`text` / `explanation`).
- **الوضع الليلي** يُطبَّق عبر سكربت صغير في `<head>` قبل أول رسم لتفادي وميض الشاشة.
- **التخزين المحلي** يُقرأ عبر `useSyncExternalStore` مع لقطة خادم فارغة، فلا يحدث اختلاف تصيير (hydration mismatch).
